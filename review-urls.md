# Review source URLs — thesolutionarchitect.uk

These are raw GitHub URLs for every reviewable page and post. They are served by
GitHub (`raw.githubusercontent.com`), not Netlify, so they bypass the site's UK
geo-firewall and can be read from anywhere.

**For the blog, review the Markdown (`content/blog/*.md`) — that is the source of
truth. The matching `*.html` files in the repo root are generated from it by
`build-blog.js`, so any correction goes in the `.md`, not the `.html`.**

If a link 404s, the repository is private — raw URLs only resolve for public
repos. In that case either make the repo public or paste file contents directly.

Base: `https://raw.githubusercontent.com/ChrisLewis1927/thesolutionarchitect-website/main/`
